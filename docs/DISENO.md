# Sistema de Diseño: Ciudad Neón (Flutter)

- **Concepto visual:** Mapa vivo como pantalla principal, modo oscuro primero con tema claro completo, glassmorphism sobrio.
- **Tokens cromáticos:** Azul-negro profundo, cian eléctrico, violeta, verde lima y ámbar/coral.
- **Tipografía:** Space Grotesk (títulos) e Inter (lectura).
- **Accesibilidad:** Contraste WCAG AA, ajuste de reducir movimiento.
